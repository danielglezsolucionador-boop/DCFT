# SUNAT Dataset Foundation

This directory is the controlled intake area for public SUNAT regulatory datasets.

It does not contain synthetic datasets. Files are admitted only when they are manually downloaded or otherwise acquired from an approved public source and registered with provenance metadata.

## Directory Layout

- `sources/sunat_sources.json`: approved public source registry.
- `raw/`: manually acquired source files.
- `metadata/`: generated provenance manifests for each acquired file.
- `processed/`: normalized outputs generated after later validation phases.

## Intake Rules

1. Use only public and approved source URLs listed in `sources/sunat_sources.json`.
2. Do not scrape authenticated, rate-limited, private, or restricted services.
3. Do not create inferred tax facts without storing the source, hash, version, and effective date.
4. Every raw file must have a matching metadata JSON generated by `tools/sunat_dataset_registry.py`.
5. A dataset remains `manual_review_required` until a human validates legal scope, source integrity, and update cadence.

## Current Scope

Foundation only:

- source identification
- controlled manual download pipeline
- metadata schema
- version/hash registration
- provenance validation

No production tax advice or automated SUNAT action is enabled by this directory.
